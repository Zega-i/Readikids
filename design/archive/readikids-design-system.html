🎨 ReadiKids AI — Design System

Satu aplikasi, dua bahasa desain: Kid Mode (hangat, membulat, besar, nyaris tanpa teks) dan Companion Mode (tenang, jelas, kredibel seperti aplikasi kesehatan). Semua token di halaman ini telah lolos uji kontras WCAG dan uji buta warna (CVD) secara programatik.

6 · Aturan Emas (masuk CLAUDE.md)

#Aturan
1Semua warna WAJIB dari token — dilarang nilai hex hardcoded di komponen.
2Kid Mode: target sentuh ≥56px, font Baloo 2 ≥17px, tanpa teks paragraf, tanpa skor/hasil/status, TTS untuk semua instruksi.
3Companion: bahasa observasi (lihat tabel Voice), badge kategori selalu ikon+label, disclaimer skrining di setiap tampilan hasil.
4Warna status ≠ warna chart ≠ warna dekoratif — tiga kelompok terpisah, tidak saling pinjam.
5Tanpa animasi/distraksi visual selama trial game berjalan — menjaga validitas telemetri.
6Kontras teks ≥4.5:1 (badan) / ≥3:1 (teks besar & grafis). Jangan tambah warna baru tanpa uji kontras+CVD.
