# Font OpenDyslexic

Unduh `OpenDyslexic.otf` (lisensi SIL OFL, gratis) dari https://opendyslexic.org
lalu letakkan di folder ini dengan nama persis `OpenDyslexic.otf`.

`src/index.css` sudah mendeklarasikan `@font-face`-nya, dan Tailwind
menyediakan utility `font-dyslexic` (lihat `tailwind.config.js`).
